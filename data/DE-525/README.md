### Page images

The PAGE files were made from pages of the PDF file of the volume
(Theil 1, Criminal-Ordnung), rendered at 300 dpi. To get the images again:

```
curl -o vol.pdf https://digital.ub.uni-potsdam.de/download/pdf/120812
for x in Criminal-Ordnung.pdf_page_*.xml; do
  n=${x#*_page_}; n=${n%.xml}
  pdftoppm -r 300 -f $n -l $n -x 0 -y 0 -W 2480 -H 3508 -png -singlefile vol.pdf Criminal-Ordnung.pdf_page_$n
done
```

Page 1 of the PDF file is a cover page generated by the library. The scans
inside the PDF file have only about 120 dpi; the images of the `MAX` file
group of the METS file are better, but the coordinates do not refer to them.
